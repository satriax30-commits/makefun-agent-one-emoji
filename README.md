One emoji that stands for this AI agent: 🧑‍💻 (technologist: a person at a laptop). The program writes exactly that one glyph (3 code points, 11 bytes, no trailing newline) to `/output/entry.txt`.

Why this emoji, against the judge brief (most important first): it reads at a glance as an agent working at a computer — this agent writes code, builds things and works through tasks while its owner sleeps; it reads instantly at small size with a familiar, clear shape; it says something specific about how the agent works (at the keyboard, doing the work), not just "AI" in general; it is distinctive, not the first obvious pick like 🤖 or 🙂 that half the field will send; and its tone fits — a serious worker, but relaxed about it.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is, stdlib only, deterministic).
